# 预训练策略对墙迁移：五轮结论

**五轮测试已完成。所测冻结模型均未直接完成对墙接回；JuggleRL已有壁球迁移训练能产生少量回合，但仍不稳定。**

| 测试对象 | 球碰墙场景 | 接回场景 | 结果范围 |
| --- | ---: | ---: | --- |
| VolleyBots 二传＋恢复 | 8/16 | 0/16 | 原切换、墙碰后重启两组结果相同 |
| HCSP 接发球＋恢复 | 1/16 | 0/16 | 两组结果相同；首次机体击球仅3/16 |
| JuggleRL 原垫球actor，零样本 | 0/100 | 0/100 | 1560次合法拍面接触，95场到时限 |
| JuggleRL 既有壁球迁移，双技能诊断 | 48/100 | 4/100 | 本轮复核历史实测；不同训练预算 |
| JuggleRL 既有迁移，拟合单actor | 48/100 | 3/100 | 本轮复核历史实测；不同训练预算 |

VolleyBots测试使用其公开权重，经兼容HCSP单机Set容器加载；HCSP接发球测试使用构造同侧来球、Receive观测与原PRT接口。未测试完整3v3高层对抗策略。部分二传/攻击权重跨两个项目完全相同，不能作为独立算法结果。

JuggleRL固定上游仓库没有随库权重，测试模型是本项目按原始垫球任务训练得到的32.768M checkpoint，不能称为作者发布预训练模型。零样本移植保持原动作，新增墙面特征未被模型使用。

这些数字不能直接横向排名：前两项是Iris/PRT、5g球、原机体接触；JuggleRL采用Air/CTBR、47.2g球和独立合法拍面，来球与墙位也不同。前两项接触以20ms读数核验，零结果是“未观察到”，不是不可达证明。纳入终止区间的敏感性检查也未发现接回链。

目前能支持的工程判断：场景相似不足以保证策略直接迁移。JuggleRL的持续拍面控制可作基础；出球目标和完整回合仍需专门适配。HCSP的技能衔接思想可以参考，但本次公开技能加墙或重新启用接球并未自动解决任务。没有证据支持继续仅靠替换现成权重即可获得稳定壁球。

本次目标是测试迁移能力，不要求测试必须成功。五轮工作已经完成，原AeroWall完整实施目标仍未达标。本批没有后台训练或评测继续运行。

详细复现配置、权重来源、逐轮修改和证据见《预训练策略对墙迁移-五轮记录.md》及《pretrained-wall-final-verification.json》。
