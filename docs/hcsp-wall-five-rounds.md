# HCSP模型单机对墙RL：五轮执行记录

目标：沿用HCSP的Iris、可见球拍、5克/0.1米小球及材料参数，用PPO训练一架无人机从固定投球开始连续对墙击球。可重复3轮为保底、5轮为主目标，最终制作约30秒真实进步演示。

## 第一轮：模型与资产合同

静态审计使用HCSP提交`009961b8f5702dd0c1c943cef0e01e09dfcd138d`。确认Iris与IrisTest引用同一个`iris_batVisualOnly.usd`和`iris.yaml`；配置质量1.52千克。球质量0.005千克、半径0.1米，球与无人机材料参数恢复系数0.8。

可见球拍网格没有CollisionAPI。实际球速变化来自`base_link/collisions`，HCSP再以无人机上方半径0.2米、高度为两个球半径的圆柱区域判断合法拍面击球。这是原HCSP模型的一部分；本项目保持该行为，不额外添加拍面碰撞体。训练计分必须同时要求物理球速/接触变化和该几何区域，避免仅凭接近拍面计分。

第一轮静态合同已通过。下一轮运行独立物理接触矩阵，验证中心、边缘、机身、墙面与落地，并确认固定投球初始化和逐子步事件顺序。

## 第二轮：单机环境与接触分类

新增单Iris对墙环境，保持HCSP原PRT动作链。物理步长0.0025秒、每个策略动作保持8个物理子步，控制周期仍为0.02秒；每个子步读取球速变化，避免碰撞和反弹发生在同一控制周期内而漏检。

5场初始化夹具全部通过：拍面中心被识别为合法触球；接近0.2米几何边缘的接触仍合法；超出拍面范围但与机身发生物理碰撞的事件被判非法；墙面使球的x速度从负变正；落地在子步内被捕获并终止。环境运行时不会改写球的运动状态，状态写入仅用于episode初始化和本轮夹具设置。

本轮使用物理速度突变与几何区域组合分类，足以供并行训练使用。最终评估仍须用独立接触报告复核，不能仅用训练环境自己的事件计数证明成绩。

## 第三轮：PPO训练链与检查点回载

使用HCSP原生`MAPPOPolicy`的单智能体PPO路径，在64个并行环境中完成5次更新，共20,480环境帧。五次更新的actor梯度范数为5.12–5.37，critic梯度范数为0.40–0.62；策略损失和价值损失均为有限值，说明采样、优势估计、反向传播和优化器链路均在工作。

训练前后参数的稳定摘要不同；保存检查点后，重新构造策略并逐个参数张量比对，完全一致。首次验证曾错误地比较两次`torch.save`产生的文件字节；该序列化格式不保证字节稳定，现已改为按参数名、形状、数据类型和张量内容计算摘要，并以`torch.equal`核对回载。这一修正只影响审计逻辑，不改变训练。

## 第四轮：稀疏奖励基线与较长训练

先在128个Stage A首局上建立未训练基线：平均回报0.096，合法击球、墙反弹和完整回合全部为0，所有episode均因球落地结束。随后从相同初始权重训练50次更新、409,600环境帧。检查点保存和逐张量回载通过，但在相同seed=123、相同128个初始条件上的确定性评估仍为0次合法击球、0次墙反弹、0个完整回合，平均回报降至0.091。

本轮结论：只有极弱的球机距离奖励时，critic可以把explained variance提高到0.90以上，但actor没有获得第一下拍面接触。球第一次下落期间仅约有34–38个控制步，稀疏接触奖励不足以指导PRT策略在这段时间内保持稳定并对准落点。

## 第五轮：HCSP式悬停塑形与几何诊断

加入与HCSP低层技能同型的姿态塑形：目标位置为当前落球点正下方2米，奖励同时衡量位置、朝向、竖直姿态与偏航角速度。修改后先重跑5项物理接触矩阵，全部通过。随后从头训练100次更新、819,200环境帧；参数变化和检查点逐张量回载均通过。

在相同128局确定性评估中，平均回报由未训练的0.096升至63.711，但合法击球、墙反弹和完整回合仍全部为0。这是明确的奖励投机：策略提高了姿态/存活回报，却没有完成任务事件。轨迹几何诊断显示，球与无人机最接近时轴向距离中位数0.137米，处在合法拍面高度0–0.2米内；但径向距离中位数0.619米、最小值0.432米，均大于合法半径0.2米。无人机姿态仍较竖直（最近点up-z中位数0.963），失败主因是水平落点跟踪偏差，不是球速过快或姿态翻转。

## 五轮后的判断

HCSP资产、物理事件、PPO训练链和可重复评估已经打通，但当前策略尚未学会第一下触球，不能进入墙后回接训练，也不能据此制作宣称成功的3轮或5轮demo。下一轮应把Stage A继续拆成“定点悬停预训练→固定高度慢投球→逐步提高投球高度/下落速度”，并将二维水平误差设为主导课程指标；只有独立评估的合法触球率达到门槛后，再解锁发向墙面的速度目标。当前结果也说明主要难点发生在首次落点对准，尚无证据支持“墙回弹过快导致失败”。
