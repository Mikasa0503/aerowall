# AeroWall 单策略拟合检查

目的：将已有击球/恢复两分支的行为拟合到一个 43 维输入的 actor，作为后续全阶段 PPO 初始化。教师仍仅有 4/100 开发接回率；拟合不是新任务成功证明，也不会自动消除教师的缺陷。

教师来自 `predictive-recovery-dev-002/frames-000033792000.pt`，两分支冻结。使用原生 WallRally、同一 CTBR 和碰撞规则新采集训练轨迹，seed=17；不加载冻结的 100 场开发 roster。学生从教师的击球分支初始化，以实际执行分支的高斯动作分布为目标，最小化 KL(teacher || student)，每个 minibatch 对存在的击球、恢复两类损失各取均值后平均。模型仍是单个原有 MLP，不保留执行时的双 actor 切换。

最后四分之一环境 ID 的所有采样留作验证，其余用于拟合；没有把相邻时刻随机拆到两边。留出集仍来自教师驱动的状态分布，不能证明学生执行后的分布或闭环性能。critic 不训练；输出 checkpoint 用于评测或下一轮 `--initialize-policy`，不能作为相同 PPO 优化器状态的恢复点。计入来源全部 33792000 步及新采集的所有环境转换。

解析检查通过：KL 与 PyTorch 分布实现一致，相同分布为零，分支均衡及缺少某分支的 batch 有效，学生梯度有限。原生 `skill-distillation-smoke-01`：16 环境、2 个采样 batch，共 2048 步，1536 个训练样本、512 个留出样本，10 个拟合 epoch；退出与报告均通过，教师参数未改变，单 actor checkpoint 重载动作精确一致。

恢复拟合改善但原击球拟合退化，不能只选择报告一侧。动作误差的单位是原始 CTBR actor 输出，不等于物理速度误差。当前仅验证数据/学习/存储路径。

已启动 `skill-distillation-dev-001`：128 环境、8 个新采样 batch（65536 步）、40 个拟合 epoch、minibatch=512，预计来源加采样共 33857536 步。不继承短训更新；完成后须独立固定场景评测。证据为 `skill-distillation-contracts.json` 和 `skill-distillation-smoke-01.json`。

该轮现已完成，进程/报告通过，教师两支参数未改变，单 actor checkpoint 保存重载动作一致；实际累计环境步 33857536。训练样本 49152、留出样本 16384。留出击球分支 12425 行：平均 KL 0 → 0.04262，动作均值 RMSE 约 0 → 0.01422；恢复分支 3959 行：KL 139.0821 → 0.07179，RMSE 0.98434 → 0.02223。较短程检查误差更低，但这是不同采样规模和状态集，不是相同验证集上的严格消融。

`skill-distillation-eval-01` 已用相同冻结 100 场景启动真实单策略评测。拟合误差不等于接回率，教师驱动数据也不能保证学生闭环状态分布稳定。新增 PPO 入口约束会拒绝将此类 checkpoint 用作 `--resume`，应使用 `--initialize-policy` 新建 critic 和优化器。

固定评测现已完成，退出/报告及独立接触事件审计通过：48/100 场碰墙、3/100 场合法接回、173 次合法拍面接触、无连续两次接回、0 次目标联合回合。接回场景为 51、68、89，分别最终无人机碰墙、触地、碰墙；全体失败原因为 30 球碰机体、32 越界、21 无人机碰墙、15 非拍面、2 触地。教师同场景为 48 场碰墙、4 场接回；直接复制恢复 actor 后 PPO 25 次为 26 场碰墙、0 场接回。这里只作不同初始化路径的开发描述，预算和训练方式不同，不是等预算方法优劣结论。证据：`skill-distillation-eval-01-audit.json`、`skill-distillation-comparison.json`。

已启动 `distilled-wall-ppo-dev-001`：从拟合 actor 初始化原有单策略 PPO，critic、值归一化与优化器新建，128 环境、100 次更新，每 25 次保存。全部阶段由单一 actor 学习，无固定教师分支参与执行。来源及采样的 33857536 步保留计数，新增预算 819200 步，预计最终累计 34676736 步；当前尚未取得该轮训练后的成功率。
