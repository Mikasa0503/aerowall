# 研究贡献与当前状态

## 项目贡献

AeroWall 基于 VolleyBots 的通用训练与仿真能力，围绕单架无人机对墙连续击球构建任务专用研究代码：

1. 构建单无人机对墙击球场景、合法拍面／墙面事件和连续回合状态管理。
2. 实现冻结发球与持续回接的技能链，当前最佳方案为冻结 Launch 加 C350。
3. 扩展壁球任务所需的观测信息，并探索连续击球、回中等奖励目标。
4. 组织分阶段策略训练、扰动课程与固定协议的评测。
5. 建立物理接触、reset、策略交接、执行器限幅和检查点身份审计，提升结果可核验性。
6. 保存批量评估、逐事件物理核对和验收演示证据。

VolleyBots、JuggleRL、HCSP 和 Isaac Sim 的通用框架、训练算法或仿真能力保持其原名称和来源。AeroWall 对任务环境、观测／奖励变体、策略路由与审计工具的具体扩展单独归属。

## 最优方案与证据

当前选定基线为冻结 Launch 发球策略 → C350 持续回接策略，检查点文件保留原名和 SHA-256。正式协议中 128/128 场均达到 17 轮并运行至 1,200 策略步上限；另有一个展示种子完成 25 轮后自然落地。正式批量和单次展示不可互相替代，详见 RESULTS.md 与 MODEL_CARD.md。

## 拓展工作状态

| 方向 | 已完成 | 当前结论 |
|---|---|---|
| 多样初始来球 | 训练和首击评测 | 首击有改善；持续回合能力尚未达标 |
| Launch／Hit／Recover 拆分 | 分阶段实现并训练 | 尚未证明优于 C350 双策略 |
| 新观测与因果奖励 | 版本化实现、奖励和观测诊断 | 有工程与诊断价值；整体性能收益未成立 |
| Tanh／有界动作 | 执行器动作映射实验 | 减少限幅；尚未证明稳定提高续拍 |
| reset、交接、执行器、模型身份审计 | 增加审计和对照工具 | 工程成果，提高实验可信度；不单独声称策略性能提升 |
| 高层策略与共同适应 | 尚未完成 | 不计作已有贡献 |

## 发布时的表述边界

- 17 轮是 128 场在 1,200 策略步上限内的结果；全部样本达到上限时仍在击球，所以不能表述为自然终止时的平均寿命。
- 25 轮来自一个专门选择的演示种子，不是跨种子统计结论。
- 首击改善、动作限幅减少和审计完整性分别对应技能信号、执行器诊断和工程可信度；不能互相替代，也不能合并成持续回合能力提升。
- 高层策略、共同适应、随机化泛化和正式三种子能力提升仍是后续工作。
