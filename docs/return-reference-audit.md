# AeroWall 回球参考预测检查

新增 `return_reference.py`，仅用当前 actor 观测中的球位置/速度、墙面位置/法向、阶段，以及固定有效恢复系数先验 0.8，预测球心下降到 1.123 米时的位置和剩余时间。该高度对应 nominal 机体 1 米、拍面上缘 0.083 米及球半径 0.04 米之和；它不是实际姿态变化后的拍面接触高度。

模型假设只有重力、静止竖直墙面、最多一次未来墙碰撞。当前预测有效时间范围为 0–1.5 秒；无效几何、非有限值、无下降交点、非出球/回球阶段明确无效。返回未来是否碰墙的标记：若高度交点早于墙接触，不能当作墙后接球参考。预测不修改输入，不访问未来仿真状态，不保证无人机能到达该位置。

解析检查通过：自由弹道、一次反射、已经反弹回来的球、无效输入/几何屏蔽、输入不修改。实际轨迹核验使用 `wall-outbound-eval-100-01` 的零延迟 actor 观测，后续保存状态仅用于离线误差比较，不传给预测器。

100 个 episode 中 44 个有计分墙接触。墙前和墙后预测各有 9 个未被后续接触或终止打断的下降交点可比较、33 个没有可用连续交点、2 个预测无效。墙前预测 XY 误差中位数约 3.9 mm、最大 33.8 mm；墙后约 2.4 mm、最大 4.5 mm。真实交点由 20 ms 保存轨迹线性插值，具有采样误差。这些条件误差不代表全场景鲁棒性，也不代表接回成功。

在同一 9 个可比较场景中，实际球心下降交点距固定 home=[0,0] 的水平距离中位数为 0.632 米、最大 0.951 米，提示固定回位与拦截球可能是不同目标。下一候选实验应把当前观测计算的接球参考与固定 home 恢复对照比较，保持真实回合评分，避免把参考预测准确当成飞行可达或拍面碰撞成功。

证据为 `return-reference-contracts.json` 和 `return-reference-outbound-100-v2.json`。v2 限定计分墙接触，排除终止/非法优先碰撞时刻，且要求插值交点确实位于墙接触之后。模块尚未接入策略动作或训练奖励。
