# AeroWall 显式弹性估计器开发检查

当前实现是观测历史估计模块，尚未接入 Estimator-PPO 训练，也没有完成墙面随机化、三种子对比或正式测试。

`aerowall/learning/restitution_estimator.py` 仅接收策略实际可见的 43 维观测与活动槽位掩码。利用可见的 TO_WALL→TO_BAT 切换定位碰撞所在观测间隔，针对已知的 0/1/2 步速度延迟，等待对应样本后计算静止竖直墙面的出射/入射法向速度比。没有读取真实材质、碰撞回调、冲量或仿真器额外状态。

首次有效样本替换 0.8 先验；后续使用系数 0.5 的指数更新，并提供样本支持度、速度比方差与本步更新标记。样本支持度为 count/(count+1)，只是启发式信息，不是校准的置信概率。低入射速度、缺少反向速度、超出合理速度比范围、等待期间阶段中断、无效观测会拒绝更新。episode 重置清空对应槽位的全部历史与估计。

解析观测序列检查通过：0/1/2 步延迟对齐、持续接触阶段不重复更新、选择性重置、低速与符号检查、异常比值、等待中断、非有限历史拒绝、停用槽位不更新。证据为 `restitution-estimator-contracts.json`。这些是算法契约检查，不能代替真实延迟环境验证。

真实记录回放使用 `wall-outbound-eval-100-01` 的 8376 个首次 episode 策略观测，44 个场景获得一次有效估计。估计完成后才读取事件文件做独立审计：44 个均为相应观测间隔内唯一的墙面接触，估计速度比与碰撞子步速度比最大绝对误差 2.90e-8。事件信息只用于比较，未进入估计器。证据为 `restitution-estimator-replay-100.json`。

尚未覆盖真实延迟、观测噪声、随机墙面与突变、低速物理碰撞、同一观测间隔多次接触。仅凭策略观测无法总是排除间隔内未观测到的多次碰撞，因此“有效”只表示可见检查通过，不代表真实参数已被准确识别。该模块估计的是有效反弹速度比，不将墙面材质配置值当作有效恢复系数。
