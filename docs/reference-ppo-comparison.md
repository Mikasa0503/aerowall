# AeroWall 参考策略约束开发对照

目的：检验全阶段 PPO 的技能退化能否通过冻结参考分布约束缓解。这是针对已测行为漂移的一次限定预算实验，不是 HCSP 完整复现，也不引入多 actor 执行。

当前旧路线 `distilled-wall-ppo-dev-001` 已完成100次更新、累计34676736环境步，实际进程结束。训练分段回合数为13、3、1、1；固定场景第25/50次均0/100接回。保留模型与日志，不追加该路线预算。

新实现 `ReferenceWallPolicy` 在 PPO actor loss 中增加 `1.0 * mean KL(current || frozen_reference)`；参考为拟合后的单 actor。物理、任务奖励、CTBR、终止规则与可见信息不变。HCSP 原实现通过环境奖励惩罚 KL，本实现是直接可微损失变体，二者不混称。

参考参数与学习参数独立复制并 detach，不进入 actor 优化器，每次更新检查逐参数精确不变；checkpoint 保存参考分布及配置，resume 必须匹配配置与方法。评测仍仅执行学习 actor，参考不参与动作选择。

验证已完成：
- 真实网络与优化器的零优势检查：初始同权重 KL=0；人为扰动后 KL 0.0318092，经单步更新降至0.0288118；参考无梯度且未变化。
- `reference-ppo-smoke-01`：16环境、2次更新、2048步，原生采集/PPO/退出与报告通过；初始化64观测动作精确一致，参考未变，保存重载动作精确一致。

正式开发对照 `reference-ppo-dev-001`：从原拟合checkpoint 33857536步重新初始化，不继承smoke。seed=0、128环境、25次更新、204800新增步，最终应累计34062336；与无约束PPO第25次有相同来源与交互预算。KL系数1.0本轮固定，不因中途结果调整。新增debug分布输出用于损失，不新增actor观测或执行分支。

评测与决策在结果产生前固定：同一冻结100场景、10秒、dt=.0025；须完成事件链审计、与无约束第25次以及拟合初始模型对照。若接回场景数不超过初始化3/100，不追加同类训练预算，转向控制可达性诊断；即使超过，也仅说明值得进一步开发，不等于统计显著改善或达到70%门槛。另记录碰墙、目标联合回合、失败原因及动作漂移，不用训练奖励替代接回成功率。

当前状态：25次更新开发训练已启动，结果待验证。完整实施计划仍未完成。
