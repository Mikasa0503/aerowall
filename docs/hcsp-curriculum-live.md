# HCSP课程继续执行记录

目标仍为A0定点悬停、A1固定慢投球、A2投球课程达标后训练发墙及回接。五轮是实验组织方式，不以执行次数代替能力验收。

## 当前证据与修正

- 早期26→46维迁移改变了输入LayerNorm，零填充输入权重不能保持原策略。A0/A1/A2目前保持HCSP Goto的26维观测。
- 随机偏移A0评估及819,200帧微调均未过门槛。固定起点也失败。不能把这些结果归因于RL训练难度：随后发现仿真首步异常冲量，必须先修复环境。
- 转子响应系数0.43与dt无关，原实现每20ms调用8次滤波。现每个控制周期更新一次，其余子步保持转子推力。此修改单独复测仍未解决A0失败。
- Orbit导入时要求NVIDIA/Isaac目录存在，导致无需在线资产的任务在Nucleus查询上阻塞。项目配置本地命名空间，仅提供目录，不伪装完整资产包；实际缺失资源仍按文件路径报错。接触矩阵在该配置下通过5项测试。
- 首步轨迹：20ms即出现侧向速度约1.58m/s、偏航角速度约10.2rad/s。场景源码显示上游无人机占位点x=0与新增墙重叠。已将无人机和球在初次sim.reset之前移至合法起点；正在复测，修复效果尚未确认。
- A0通过条件必须同时包含完整时限、无碰地碰墙、平均末100步水平误差<0.1m及至少90%episode达标。A1/A2要求合法物理触球率≥80%。最终成绩还需要独立接触证据。

## 初始化修复后的结果

修复无人机在场景构建阶段与墙体重叠后，首步侧向速度由约1.58m/s降至约1e-6m/s，偏航角速度由约10.2rad/s降至约1e-5rad/s。

- A0：官方Goto权重、固定起点、128首局均完整运行600步/12秒，无终止失败；末100步水平误差均值0.05494m，100%低于0.1m。无需采用已退化的旧环境微调权重。
- A1：固定2.8m高度、-0.25m/s投球，128/128合法触球；128次均由独立PhysX报告复核，seed=456。
- A2：水平偏移±0.15m、投球高度2.8–4.8m、向下速度0–0.75m/s，128/128合法触球；128次均由独立PhysX报告复核，seed=789。
- 关键结论：此前零触球并非已证明的RL能力局限；物理初始化重叠使策略起步即遭受不合理冲量。旧环境训练检查点保留作诊断，不用于当前课程。

## 发墙训练

使用分开的26维悬停特征LayerNorm和20维新增球状态LayerNorm，保留原策略。64组随机输入的扩展前后确定性动作最大误差3.58e-7，通过1e-5容差校验。原始零填充不能保持全局LayerNorm，已替换。

首批WALL训练：50次更新、128环境、每次8192帧、actor学习率2e-5，从官方Goto权重初始化；须提供A2门槛报告才能启动。奖励集中于合法触球后的出射速度及前墙事件，首次墙接触结束该技能episode。目标出射速度约vx=-2.3m/s、vz=6.5m/s，旨在保留回接时间；这是待训练目标，不是已实现能力。回接尚未训练。

当前训练输出：runs/hcsp-wall-goal2-wall-train-01.json。全目标保持active，不因课程三道门槛通过而标记完成。

## 发墙达标与回接训练

首批发墙409,600帧完成。128首局均发生合法击球和真实前墙反弹；128次击球、128次墙事件均由独立PhysX报告佐证。代表性出射速度[-2.317,0.550,6.104]m/s，墙面碰撞高度约3.999m。该结果证明固定投球发墙成功，尚不证明连续回接。

同一发墙策略继续运行的128局回接为0。冻结发墙直到首次墙反弹，回接actor从官方Goto权重初始化；观测添加下降至z=2.18m时的预测接球位置。PPO训练过滤掉冻结前缀的动作样本及其熵损失，只优化接管后的actor动作。仅episode初始化写入物理状态。

5次回接更新验证通过，检查点回载一致，冻结发墙策略逐张量不变。首批50次回接训练在runs/hcsp-wall-goal2-return-train-01.json，统一exec会话73665。需在结束后使用--stage RETURN、--checkpoint对应回接权重、--launch-checkpoint runs/hcsp-wall-goal2-wall-train-01.pt评估。完整目标仍未完成。

## 当前阶段收口

上述等待墙碰撞接管的50次更新未成功：回接0/128，接球时侧向落后约0.43m。最终修正为首次击球后即接管，并在球飞向墙时预测反弹接球位置，保留约0.56s额外移动时间。该配置原生Goto回接128/128；再以5e-6学习率PPO微调10次、81,920帧后，最终128/128完成一轮。256次合法击球、128次墙事件全部由独立PhysX报告佐证。

最终权重：发墙runs/hcsp-wall-goal2-wall-train-01.pt；回接runs/hcsp-wall-goal2-return-early-train.pt。最终评估runs/hcsp-wall-goal2-return-final-eval.json。发墙冻结、权重回载与回接权重变化均通过。
